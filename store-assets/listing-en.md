# SEO Copilot — Chrome Web Store English detailed description

SEO Copilot is a Chrome extension for checking on-page SEO on the page you're viewing. Open a webpage, run the extension, and review its title tag, meta description, headings, images, canonical link, JSON-LD structured data, URL, and visible content.

Check the current page's SEO title for missing, short, long, or multiple title tags. Check its meta description for missing text or length issues. The report groups findings by severity and explains why each issue matters.

For supported title and meta description issues, you can request AI suggestions when you need them. Review the suggestions, make changes to your website yourself, and scan the page again to check the result.

How it works:

1. Open the page you want to check in Chrome.
2. Click SEO Copilot and analyze the current tab.
3. Review the SEO score and issues for the page.
4. Request an AI suggestion for a supported title or meta description issue if helpful.
5. Update your site in your own editor or CMS, then scan again.

The basic scan runs locally in your browser and does not require an account. Page context is sent for AI suggestions only when you request one. SEO Copilot does not edit your website automatically.
