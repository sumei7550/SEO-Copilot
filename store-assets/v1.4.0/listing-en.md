# SEO Copilot 1.4.0 — Chrome Web Store copy (English)

## Short description

Audit webpages, find on-page SEO issues, and get AI-powered title and meta description suggestions directly in Chrome.

## Detailed description

SEO Copilot is an on-page SEO checker for the page open in Chrome. Run a page-level SEO audit to find issues and see what needs attention.

Start in the popup to review the current page's title, meta description, URL and headings. You can also inspect canonical and other indexability signals, explore collected structured data, and review image URLs, dimensions and alt text. Filter images with missing or empty alt text, check image URL status when available, and export the image list.

Open the SEO report for a deeper review: a 0–100 score, issues grouped by severity and category, explanations of their impact, and recommended actions. For supported popup warnings, View issue takes you to the matching audit issue in the Side Panel.

For supported title and meta description issues, you can request optional AI title and meta description suggestions. Compare the options, copy the one you prefer, make the change in your CMS or code, and re-scan the page. SEO Copilot does not automatically edit your website.

### What you can do

- Check titles, meta descriptions, headings and page URLs.
- Review canonical, robots, sitemap and hreflang signals when available.
- Explore structured data found on the page. Rich-result eligibility is not validated.
- Find missing or empty image alt text; filter and export image details.
- Review an SEO score, issue severity, impact and recommended actions.
- Request AI title or meta description suggestions for supported issues, then re-scan after editing.

SEO Copilot checks the page you are viewing; it is not a site-wide crawler. Basic page analysis runs in the extension. Image status and indexability checks may request relevant websites. When you explicitly request an AI suggestion, the page context needed for that suggestion is sent to the SEO Copilot backend and its AI provider. Review AI suggestions before using them; no tool can guarantee a change in search rankings.
