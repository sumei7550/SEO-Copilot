# SEO Copilot 1.4.0 store screenshots

Five 1280 × 800 English screenshot drafts. Run `build.ps1` to regenerate them.

The UI inside each frame comes from existing 1.4.0 user captures copied into `source/`. It is not reconstructed or altered. The text and lavender background are store presentation artwork.

- `content.png`: Content popup on Backlinko.
- `indexability.png`: Indexability popup on CMLabs.
- `structured-data.png`: expanded structured data popup on Backlinko.
- `images.png`: Images popup on GPS Phone.
- `report.png`: Side Panel report on MyJobSuccess.

These drafts should be reviewed for site permissions, current release build fidelity, and Chrome Web Store listing policy before upload. No screenshot shows AI suggestions because the available current-release capture does not show that state.
