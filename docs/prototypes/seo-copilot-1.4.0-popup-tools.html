Tools beside the page data

Six left-hand tools share one Popup. The right pane shows sample scan data where it exists and names fields that still need implementation. This standalone prototype does not read the active tab or run an audit.

Prototype controls are outside the Popup. Metadata is already implemented in the current Popup; Word Count, headings, canonical, schema and image fields exist in the full scan but are not yet Popup tools. Social and Links have no scanner data today.
