# SEO Copilot 产品规格文档（最终版）

# 1. 产品定义

## 1.1 产品名称

SEO Copilot

## 1.2 产品类型

Chrome Extension（浏览器插件）

## 1.3 产品定位

SEO Copilot 是一个帮助网站运营者快速发现网页 SEO
问题，并提供优化建议的浏览器插件。

目标用户： - 独立站卖家 - SEO Freelancer - 内容运营人员 - 网站管理员

核心价值：

> 从"SEO检测工具"升级为"SEO优化助手"。

传统工具： 发现问题。

SEO Copilot： 发现问题 → 解释原因 → 提供解决方向。

------------------------------------------------------------------------

# 2. 产品目标

用户使用插件后，可以：

1.  快速判断网页 SEO 健康状态
2.  找出影响页面表现的问题
3.  理解问题为什么重要
4.  获取下一步优化建议

# 5. 功能模块

## 5.1 SEO Scanner

检测：

-   Title
-   Meta Description
-   Heading
-   Images ALT
-   URL
-   Canonical
-   Schema

------------------------------------------------------------------------

## 5.2 Title分析

检查：

-   是否存在
-   长度
-   优化建议

问题示例：

Missing Title

建议： 增加页面主题、关键词和搜索意图。

------------------------------------------------------------------------

## 5.3 Meta Description分析

检查：

-   是否存在
-   长度
-   内容质量

推荐： 120-160字符。

------------------------------------------------------------------------

## 5.4 Heading结构分析

检查：

-   H1是否存在
-   是否多个H1
-   H2/H3层级

------------------------------------------------------------------------

## 5.5 图片SEO分析

检查：

-   图片数量
-   ALT存在数量
-   ALT缺失比例

------------------------------------------------------------------------

## 5.6 URL分析

检查：

-   URL长度
-   URL结构

------------------------------------------------------------------------

## 5.7 Technical SEO

检查：

-   Canonical
-   Schema

支持：

-   Product
-   Article
-   FAQ
-   Review

------------------------------------------------------------------------
