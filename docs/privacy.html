SEO Copilot Privacy Policy

Effective date: August 8, 2026

SEO Copilot analyzes the active webpage for on-page SEO issues and provides local, actionable recommendations.

Data processed

Only after the user clicks Analyze this page, SEO Copilot temporarily reads the active tab's URL, metadata, headings, image SEO attributes and dimensions, JSON-LD structured data, and visible text required to calculate word count and text ratio.

SEO Copilot does not read cookies, passwords, form entries, authentication or payment information, browser history, or tabs the user has not chosen to analyze.

Use, storage, and sharing

  • Data is processed locally only to generate the requested SEO report.
  • Webpage data is not transmitted to the developer or any external server.
  • Scanned webpage data is not retained after report generation.
  • No data is sold, rented, shared, used for advertising, or used to create profiles.
  • V1.0.0 contains no analytics trackers or remote code.

Permissions

activeTab provides temporary access to the user-selected tab. scripting runs the packaged local scanner after the user confirms analysis. The extension requests no host, history, cookie, or persistent storage permission.

Limited Use

The use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Access is limited to the extension's single purpose: a local SEO audit of the active page.

Changes

If a future release changes these practices, this policy and the in-product disclosure will be updated before the changed processing begins.

Contact

For privacy questions, use the SEO Copilot support page.
