SEO Copilot Privacy Policy

Version: V1.1.0 Alpha · Effective date: August 30, 2026

SEO Copilot analyzes pages for on-page SEO issues and, when requested, generates title or meta description suggestions. This policy describes the current Alpha Real AI behavior.

Local SEO scanning

Only when the user actively starts an analysis, SEO Copilot reads the current active tab. The basic SEO scan runs primarily on the user's device and may inspect the URL, title, meta description, canonical URL, H1/H2/H3 headings, image URLs, alternative text and dimensions, structured data/JSON-LD, visible page text, and related SEO elements.

The extension does not automatically modify the website.

AI Fix

Only when the user actively requests an AI title or meta description suggestion, necessary page context is sent over HTTPS to the SEO Copilot backend. The request includes the issue type/current value, URL, title, meta description, H1, page language, page type, inferred brand, issue context/diagnosis, and a randomly generated device ID.

The backend sends the context needed to generate the result to the configured DeepSeek API. The extension does not call DeepSeek directly.

Do not use AI Fix on pages containing passwords, authentication information, payment information, health information, private communications, or other sensitive content. SEO Copilot does not actively read passwords, cookies, authentication credentials, payment form values, or private messages, but page fields can themselves contain sensitive information.

Services and providers

  • SEO Copilot backend: currently deployed on Vercel; receives AI Fix requests, calls the AI provider, and applies service limits.
  • DeepSeek: generates AI title and meta description suggestions.
  • Upstash Redis: supports AI quotas, IP rate limiting, device cooldowns, and the global limit; it is not used to analyze webpage content.

Retention and processing by third-party service providers are governed by their applicable service terms and privacy policies. This policy does not make an absolute retention-period promise for those providers.

Storage, device ID, and IP rate limiting

The extension uses chrome.storage.local to store a randomly generated deviceId for AI quota, cooldown, and abuse prevention. It does not contain a name or email address. The extension may also store lastInstalled and other operational data. The device ID is sent with AI Fix requests.

The backend uses the request IP for rate limiting and abuse prevention. The IP is hashed for the rate-limit key and the complete IP is not written to SEO Copilot business logs. It is not used for advertising, profiling, or marketing. Platform-level logs may still exist under applicable platform terms.

What SEO Copilot does not do

SEO Copilot does not sell user data, use data for advertising, build advertising profiles, use data for purposes unrelated to its single purpose, automatically modify websites, or guarantee ranking or traffic improvements.

Permissions

  • activeTab: access to the current tab when the user actively analyzes it.
  • scripting: inject the packaged local scanning script.
  • storage: save the device ID, installation time, and other local extension data.
  • host_permissions: https://seo-copilot-seven.vercel.app/*: connect to the SEO Copilot backend for user-requested AI Fix processing.

Limited Use

Use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including its Limited Use requirements. Access is limited to local SEO auditing and explicitly requested AI title or meta description suggestions.

Changes

If a future release changes these practices, this policy and the in-product disclosure will be updated before the changed processing begins.
