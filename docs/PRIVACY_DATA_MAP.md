# SEO Copilot V1.1.0 Alpha Privacy Data Map

| Data | Source | Purpose | Local persistence | Transmission | Recipient |
|---|---|---|---|---|---|
| Local page SEO data: URL, title, meta description, H1/H2/H3, canonical, images, image SEO attributes, structured data/JSON-LD, visible text, and related SEO elements | Current active tab, only after the user actively starts a scan | Basic SEO scan, score, issues, and recommendations | Basic scan data is used in memory for the report; no raw page data is intentionally stored by the extension | Basic SEO scanning runs locally and is not transmitted off-device | None for the basic scan |
| AI Fix page context: issue type/current value, URL, title, meta description, H1, page language, page type, inferred brand, issue context/diagnosis | Locally produced scan result and AI Fix context | Generate AI title or meta description suggestions | No extension storage of this context is intentionally performed | Via HTTPS: SEO Copilot extension → SEO Copilot backend → DeepSeek API | SEO Copilot backend on Vercel and DeepSeek |
| `deviceId` | Randomly generated by the extension | AI daily quota, cooldown, and abuse prevention | `chrome.storage.local` | Sent with AI Fix requests | SEO Copilot backend; used by its Upstash Redis rate-limit service |
| Request IP | AI Fix request received by the backend | Rate limiting and abuse prevention | Backend/service handling; retention is not specified here | Hashed server-side for the rate-limit key | SEO Copilot backend / Upstash Redis |
| `lastInstalled` | Extension installation event | Extension operation/diagnostics | `chrome.storage.local` | Not sent by the current implementation | None |

Basic SEO scanning runs locally. When the user explicitly requests AI suggestions, necessary page context is transmitted via HTTPS to the SEO Copilot backend and its configured AI provider.

## Excluded or sensitive information

SEO Copilot does not actively read passwords, cookies, authentication credentials, payment form values, or private messages. However, URLs, titles, meta descriptions, H1 text, and visible page content can contain sensitive information. Users should not actively use AI Fix on pages containing passwords, authentication information, payment information, health information, private communications, or other sensitive content.

## Chrome Web Store privacy answers

- Single purpose: locally audit the user-selected active webpage and provide explicitly requested AI title/meta description suggestions.
- Handles website content: Yes. Basic scan data is processed locally after explicit user action; necessary context is transmitted only when the user requests AI Fix.
- Handles web browsing activity: The current active page is accessed only for the user-requested scan or AI Fix flow. No browsing history is collected.
- Data sold or shared: No sale or advertising sharing. AI Fix context is shared with the SEO Copilot backend and DeepSeek only to provide the requested suggestion.
- Data used for advertising: No.
- Data transmitted off-device: Conditional. Basic SEO scanning runs locally; AI Fix transmits necessary page context via HTTPS to the backend and configured AI provider.
- Remote code: No.
- Limited Use certification: Yes.

Retention and processing by third-party service providers are governed by their applicable service terms and privacy policies. This map does not make an absolute retention-period or platform-log promise.
