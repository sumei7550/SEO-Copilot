# Extension Name

SEO Copilot – AI SEO 检查器

# Short Description

使用 SEO 检查器审核网页，发现问题，获取 AI 标题和元描述建议，并在更新后重新扫描。

# Detailed Description

SEO Copilot 是一款面向 Chrome 当前网页的 AI SEO 检查器，可快速完成页面 SEO 诊断和轻量级网站分析，帮助你了解哪些内容值得优化。

它聚焦于你正在查看的单个网页，不会替你批量修改整个网站。你可以在落地页、博客文章、商品页、价格页或文档发布前进行页面质检，也可以用它初步排查技术 SEO 问题。

运行扫描后，你可以查看 SEO 得分和检测到的 SEO 问题。检查范围包括 title 标签、meta description、H1 及其他标题层级、canonical 标签、结构化数据/schema、图片 SEO（如 alt 文本）、URL 结构及其他技术 SEO 信号。问题严重程度可帮助你安排处理顺序。

对于支持的标题和 meta description 问题，SEO Copilot 会结合当前页面内容生成 AI 标题建议和 AI 元描述建议。你可以比较多个方案，选择合适的内容，并使用 Copy selected 复制所选建议；需要不同方向时可点击 Generate another。建议用于辅助标题优化和内容编辑，最终发布内容由你决定。

## 使用流程

打开网页，启动 SEO Copilot 并运行扫描；查看 SEO 得分和问题，在 CMS 或代码中自行完成修改，然后点击 Re-scan 检查更新后的页面状态。

它适合 SEO 从业者、代理商、开发者、内容团队、博客作者、电商和 SaaS 团队以及网站所有者，可用于落地页、文章、商品页和日常页面质检。

SEO 得分应结合页面目标、内容质量和用户体验一起判断。你可以在 CMS 或代码中完成必要修改，再用 Re-scan 检查更新后的结果，形成从发现问题到人工复核的工作流程。

## 隐私与限制

SEO Copilot 仅提供页面分析和 AI 辅助建议，不会自动修改网站，也不会自动修复所有 SEO 问题，更不保证流量增长、搜索排名或 Google 排名提升。AI 建议使用前应由你检查其准确性、相关性和品牌语气。
