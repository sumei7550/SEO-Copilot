# Extension Name

SEO Copilot – AI SEO 检查器

# Short Description

使用 SEO 检查器审核网页，发现问题，获取 AI 标题和元描述建议，并在更新后重新扫描。

# Detailed Description

SEO Copilot 是一款面向 Chrome 当前网页的 AI SEO 检查器，可快速完成页面 SEO 分析，发现常见的 On-page SEO 和技术 SEO 问题，并帮助你判断哪些内容值得优先优化。

它专注于你正在查看的单个网页，不会自动批量修改整个网站。你可以用它检查落地页、博客文章、商品页、价格页、文档页等内容，也适合在页面发布前进行 SEO 质检，或在日常运营中快速排查页面问题。

运行扫描后，你可以查看 SEO 得分、问题数量和问题严重程度。检查范围包括 title 标签、meta description、H1 及其他标题层级、canonical 标签、结构化数据（Schema）、图片 alt 文本、URL 结构，以及其他常见的页面 SEO 和技术 SEO 检查项。

问题会按照严重程度展示，方便你快速了解哪些问题更值得优先处理。

对于支持的 title 和 meta description 问题，SEO Copilot 会结合当前页面内容生成多条 AI 优化建议。你可以对比当前内容和 AI 建议，选择更合适的方案并复制；如果希望获得不同方向的建议，也可以继续生成新的候选内容。

AI 建议主要用于辅助标题优化和 meta description 优化，帮助你更快完成内容编辑和 SEO 调整。最终是否采用以及如何修改，仍由你根据页面目标、品牌语气和实际内容决定。

## 主要功能

- 扫描当前网页的 SEO 状态
- 查看 SEO 得分和检测到的问题
- 检查 title 标签和 meta description
- 检查 H1、标题结构和页面层级
- 检查 canonical 标签
- 检查结构化数据（Schema）
- 检查图片 alt 文本等图片 SEO 项目
- 检查 URL 及其他技术 SEO 项目
- 获取 AI 标题优化建议
- 获取 AI meta description 优化建议
- 对比多个 AI 候选方案
- 修改页面后重新扫描

## 使用流程

打开需要检查的网页，启动 SEO Copilot 并运行扫描。

查看 SEO 得分和检测到的问题后，可以根据 Recommended Action 或 AI 建议，在 CMS、网站后台或代码中自行完成修改。

修改完成后，再次扫描页面，即可查看更新后的 SEO 状态，形成“发现问题 → 优化内容 → 再次检查”的完整工作流程。

## 适合谁使用

SEO Copilot 适合：

- SEO 从业者
- 独立站和网站运营者
- SEO Freelancer 和代理商
- 内容运营与内容营销团队
- 开发者
- 博客作者
- 电商团队
- SaaS 团队

无论是检查落地页、博客文章、商品页、价格页还是文档页面，都可以用 SEO Copilot 快速了解页面当前的 SEO 状态和可优化项。

## 隐私与限制

SEO Copilot 提供页面 SEO 分析和 AI 辅助建议。

它不会自动修改你的网站，也不会自动修复所有 SEO 问题，不保证搜索流量增长、搜索排名提升或 Google 排名提升。

AI 生成的建议应在使用前根据页面内容、准确性、相关性和品牌语气进行确认。
