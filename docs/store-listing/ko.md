# Extension Name

SEO Copilot – AI SEO 검사기

# Short Description

SEO 검사기로 페이지를 점검하고 문제를 찾아 AI 제목·메타 설명 제안을 받은 뒤 업데이트 후 다시 스캔하세요.

# Detailed Description

SEO Copilot은 Chrome에서 현재 열려 있는 페이지를 빠르게 분석할 수 있는 AI 기반 SEO 검사기입니다. 온페이지 SEO와 기술 SEO 요소를 점검하고, 어떤 부분을 우선적으로 개선해야 하는지 파악하는 데 도움을 줍니다.

사이트 전체를 자동으로 수정하는 도구가 아니라, 현재 보고 있는 개별 페이지를 대상으로 SEO 상태를 확인하는 도구입니다. 랜딩 페이지, 블로그 게시물, 상품 페이지, 가격 페이지, 문서 페이지 등의 게시 전 SEO 점검이나 일상적인 페이지 품질 확인에 활용할 수 있습니다.

페이지를 스캔하면 SEO 점수와 감지된 문제, 문제별 중요도를 확인할 수 있습니다.

SEO Copilot은 다음과 같은 항목을 점검합니다.

- title 태그
- 메타 설명
- H1 및 기타 헤딩 구조
- canonical 태그
- 구조화 데이터(Schema)
- 이미지 alt 텍스트
- URL 구조
- 기타 온페이지 SEO 및 기술 SEO 항목

문제별 중요도를 함께 확인할 수 있어 어떤 항목을 먼저 검토하고 수정할지 우선순위를 정하기 쉽습니다.

## AI 기반 SEO 제안

지원되는 title 및 메타 설명 문제의 경우, SEO Copilot은 현재 페이지의 내용을 바탕으로 여러 개의 AI 최적화 제안을 생성합니다.

현재 내용과 AI 제안을 비교하고 가장 적합한 항목을 선택해 복사할 수 있습니다. 다른 방향의 문구가 필요하다면 새로운 AI 제안을 추가로 생성할 수도 있습니다.

AI 제안은 제목 최적화와 메타 설명 개선 작업을 보조하기 위한 기능입니다. 실제로 사용할 문구는 페이지의 목적, 콘텐츠 내용, 브랜드 톤을 고려해 직접 결정할 수 있습니다.

## 주요 기능

- 현재 페이지 SEO 분석
- SEO 점수 및 문제 감지
- title 태그 및 메타 설명 점검
- H1 및 헤딩 구조 확인
- canonical 태그 확인
- 구조화 데이터(Schema) 점검
- 이미지 alt 텍스트 확인
- URL 및 기술 SEO 항목 점검
- AI 기반 title 최적화 제안
- AI 기반 메타 설명 제안
- 여러 AI 제안 비교
- 수정 후 페이지 재스캔

## 사용 방법

1. Chrome에서 점검할 페이지를 엽니다.
2. SEO Copilot을 실행하고 페이지를 스캔합니다.
3. SEO 점수와 감지된 문제를 확인합니다.
4. 지원되는 문제에는 AI 제안을 활용합니다.
5. CMS, 웹사이트 관리 화면 또는 코드에서 직접 수정합니다.
6. 수정이 끝나면 다시 스캔하여 최신 SEO 상태를 확인합니다.

## 이런 분들에게 유용합니다

SEO Copilot은 다음과 같은 사용자에게 유용합니다.

- SEO 담당자
- SEO 프리랜서 및 대행사
- 웹사이트 운영자
- 개발자
- 콘텐츠 및 마케팅 팀
- 블로거
- 이커머스 팀
- SaaS 팀

랜딩 페이지, 블로그 게시물, 상품 페이지, 가격 페이지, 문서 페이지 등을 빠르게 점검하고 개선할 항목을 정리할 때 활용할 수 있습니다.

## 개인정보 및 제한 사항

SEO Copilot은 SEO 분석과 AI 기반 제안을 제공합니다.

웹사이트를 자동으로 수정하거나 모든 SEO 문제를 자동으로 해결하지 않습니다. 또한 검색 트래픽 증가, 검색 순위 상승 또는 Google 검색 순위 향상을 보장하지 않습니다.

AI로 생성된 제안은 사용하기 전에 정확성, 관련성 및 브랜드 톤에 적합한지 확인하는 것이 좋습니다.
