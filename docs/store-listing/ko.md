# Extension Name

SEO Copilot – AI SEO 검사기

# Short Description

SEO 검사기로 페이지를 점검하고 문제를 찾아 AI 제목·메타 설명 제안을 받은 뒤 업데이트 후 다시 스캔하세요.

# Detailed Description

SEO Copilot은 Chrome에서 현재 열어 본 페이지를 분석하는 AI SEO 검사기입니다. 온페이지 SEO와 기술 SEO 요소를 빠르게 점검하고, 어떤 부분을 개선할지 판단하는 데 도움을 줍니다.

사이트 전체를 자동으로 변경하는 도구가 아니라 현재 보고 있는 한 페이지의 상태를 확인하는 도구입니다. 게시 전 랜딩 페이지, 블로그 글, 상품 페이지, 가격 페이지와 문서의 품질 점검, 기술 SEO의 초기 검토에 활용할 수 있습니다.

페이지를 스캔하면 SEO 점수와 SEO 문제 감지 결과를 확인할 수 있습니다. title 태그, 메타 설명, H1 및 기타 제목 구조, canonical 태그, 구조화 데이터/schema, 대체 텍스트를 포함한 이미지 SEO, URL 구조와 관련 SEO 신호를 점검합니다. 문제의 심각도도 확인해 우선순위를 정할 수 있습니다.

지원되는 title과 메타 설명 문제에는 페이지 문맥을 반영한 AI 제목 제안과 AI 메타 설명 제안을 제공합니다. 여러 안을 비교하고 적합한 안을 선택한 뒤 Copy selected로 복사하세요. 다른 표현이 필요하면 Generate another를 사용할 수 있습니다. 제안은 제목 최적화와 콘텐츠 작업을 돕기 위한 것이며, 게시할 내용은 직접 결정합니다.

## 사용 방법

웹페이지를 열고 SEO Copilot을 실행한 다음 스캔합니다. SEO 점수와 감지된 문제를 검토하고, 필요하면 CMS나 코드에서 직접 수정한 후 Re-scan을 눌러 최신 상태를 다시 확인하세요.

SEO 담당자, 대행사, 개발자, 콘텐츠 팀, 블로거, 쇼핑몰 및 SaaS 운영자, 웹사이트 소유자가 랜딩 페이지·게시물·상품 페이지를 검수할 때 활용할 수 있습니다.

SEO 점수만으로 결론을 내리기보다 페이지 목적과 독자를 고려해 감지 결과를 검토하세요. CMS나 소스 코드에서 필요한 수정을 직접 진행한 뒤 다시 스캔하면 변경 후 상태도 확인할 수 있습니다.

## 개인정보 및 제한

SEO Copilot은 분석과 AI 보조 제안만 제공합니다. 웹사이트를 자동으로 수정하거나 모든 SEO 문제를 자동으로 해결하지 않으며, 트래픽이나 검색 순위 또는 Google 순위 향상을 보장하지 않습니다. AI 결과는 사용 전에 정확성과 적합성을 확인하세요.
