# Extension Name

SEO Copilot – AI SEOチェッカー

# Short Description

SEOチェッカーでページを診断し、問題を検出。AIでタイトルとメタディスクリプションを提案し、更新後に再スキャン。

# Detailed Description

SEO Copilotは、Chromeで現在開いているページを確認できるAI搭載のSEOチェッカーです。ページSEOの診断をすばやく行い、改善を検討すべき箇所を把握できます。

サイト全体を自動で変更するのではなく、今見ている1ページの状態を確認するためのツールです。公開前のランディングページ、ブログ記事、商品ページ、料金ページ、ドキュメントなどの品質確認や、テクニカルSEOの初期チェックに利用できます。

スキャンするとSEOスコアと検出されたSEO問題を確認できます。titleタグ、メタディスクリプション、H1などの見出し、canonicalタグ、構造化データ／schema、画像のalt属性などの画像SEO、URL、その他のテクニカルSEO要素をチェックします。問題の重要度も表示されるため、対応の優先順位を付けやすくなります。

対応するtitleやメタディスクリプションの問題には、ページの内容に合わせたAI提案を表示します。複数の案を比較して選び、Copy selectedでコピーできます。別の案が必要なときはGenerate anotherを使えます。提案はタイトル最適化や編集作業を支援するもので、公開する内容はご自身で判断してください。

## 使い方

ページを開いてSEO Copilotを起動し、スキャンを実行します。SEOスコアと問題を確認し、必要に応じてAI提案を参考にしながら、CMSやコードで自分で変更します。最後にRe-scanを選ぶと、更新後の状態をもう一度確認できます。

SEO担当者、制作会社、開発者、コンテンツ担当者、ブロガー、ECやSaaSチーム、サイト運営者のランディングページ・記事・商品ページの確認に役立ちます。

SEOスコアだけで判断せず、検出された内容をページの目的や読者に照らして確認できます。CMSやソースコードで必要な修正を行った後に再スキャンすることで、変更後の状態を確認するワークフローにも対応します。

## プライバシーと制限

SEO Copilotは分析とAIによる提案を提供します。サイトを自動変更したり、すべてのSEO問題を自動修正したり、検索順位・Googleでの順位・トラフィックの向上を保証したりするものではありません。AIの提案は利用前に内容を確認してください。
