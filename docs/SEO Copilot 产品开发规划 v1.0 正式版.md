# 2. 项目背景

SEO Copilot 当前定位：

SEO Checker

当前能力：

-   页面SEO检测
-   SEO问题分析
-   页面结构检查
-   SEO基础优化建议

当前问题：

传统SEO工具主要解决：

发现问题

但用户仍需要：

-   理解问题原因
-   判断优化优先级
-   知道如何修改
-   实际执行优化

市场机会：

将SEO检查工具升级为：

AI SEO Assistant

# 6. 产品原则

## 不做

暂不做：

-   Ahrefs替代品
-   SEO数据库平台
-   外链数据库
-   全面的SEO SaaS系统

原因：

这些领域需要大量数据和资源。

------------------------------------------------------------------------

## 聚焦

重点：

-   AI SEO分析
-   AI优化建议
-   快速提升网页SEO质量
-   降低SEO优化门槛

------------------------------------------------------------------------

SEO Copilot采用：

-   Phase = 产品能力发展阶段
-   Release Version = 实际产品发布版本

当前线上已有版本：

v1.0.0

后续版本根据产品能力阶段逐步迭代。

-   保持小步上线
