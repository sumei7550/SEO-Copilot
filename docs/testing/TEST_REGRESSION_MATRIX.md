## 测试执行指南

### 每个网站的测试步骤
1. 在Chrome中打开目标URL
2. 等待页面完全加载（观察加载指示器消失）
3. 打开Chrome DevTools Console（F12）
4. 点击扩展图标启动SEO Copilot
5. 点击"Scan Current Page"按钮
6. 观察扫描进度和控制台输出
7. 记录结果到对应行

### 评分标准
- **扫描成功**: ✅ 完成扫描并显示结果 / ❌ 扫描失败或崩溃
- **控制台错误**: 
  - ✅ 无错误
  - ⚠️ 仅有警告（不影响功能）
  - ❌ 严重错误（红色error）
- **评分生成**: 
  - ✅ 生成完整评分
  - ⚠️ 部分类别缺失
  - ❌ 未生成评分
- **Schema解析**: 
  - ✅ 成功解析
  - ➖ 页面无Schema
  - ❌ 解析失败（页面有Schema但未识别）
- **性能表现**:
  - ✅ <2秒
  - ⚠️ 2-5秒
  - ❌ >5秒

### 失败案例处理
如果某个网站扫描失败：
1. 记录完整的控制台错误信息
2. 截图扩展UI状态
3. 尝试刷新页面重新测试（标注"重试"）
4. 如果连续2次失败，标记为阻塞问题
5. 继续测试其他网站，不要中断流程
