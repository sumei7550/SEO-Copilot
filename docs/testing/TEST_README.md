# SEO Copilot v1.0.0 - 人工验收测试包

## 📦 测试包说明

本测试包提供完整的人工验收测试方案，用于验证 SEO Copilot 扩展在 20 个不同架构网站上的稳定性和功能完整性。

## 🎯 测试目标

验证扩展的**扫描稳定性**和**结果合理性**，而非评判网站 SEO 得分高低。

### 关键验收指标
- ✅ **扫描成功率 ≥ 90%** (18/20 网站)
- ✅ **无 P0 阻塞问题** (不导致崩溃或核心功能失效)
- ✅ **静态站点 100% 成功** (基础场景必须稳定)
- ✅ **控制台无严重错误** (允许第三方警告)

## 📚 测试文档结构

本测试包包含 4 个核心文档：

### 1. **TEST_REGRESSION_MATRIX.md** (主测试表格)

- 7 大类别网站（静态/CMS/Next.js/SPA/电商/新闻/超大DOM）
- 每个网站的 6 个测试维度
- 结果记录表格和统计汇总

**用途**: 记录每个网站的测试结果

### 2. **TEST_EXECUTION_GUIDE.md** (详细执行指南)
完整的测试执行手册，包含：
- 测试前准备步骤
- 标准测试流程（6步法）
- 特殊场景测试指南
- 常见问题排查方案
- 失败案例处理流程

**用途**: 测试过程中的操作参考

### 3. **TEST_QUICK_REFERENCE.md** (快速参考卡)
一页式速查表，包含：

自动化准备脚本，执行：

**用途**: 测试前一键准备环境

## 🚀 快速开始

### 第一步：准备环境

```bash
# 方式 1: 使用准备脚本（推荐）
bash scripts/run-test-preparation.sh

# 方式 2: 手动执行
npm test && npm run build
```

### 第二步：加载扩展

1. 打开 Chrome 浏览器
2. 访问 `chrome://extensions/`
3. 启用右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择项目的 `dist` 目录
6. 确认扩展图标出现在工具栏

### 第三步：执行测试

1. 打开 [TEST_REGRESSION_MATRIX.md](TEST_REGRESSION_MATRIX.md)
2. 按照 [TEST_EXECUTION_GUIDE.md](TEST_EXECUTION_GUIDE.md) 的指引
3. 逐个测试 20 个网站
4. 在矩阵表格中记录结果

## 📋 标准测试流程

每个网站执行以下 5 步：

```
1. 访问网站 → 等待完全加载
2. F12 打开 Console → 清空日志
3. 点击扩展图标 → 点击 "Scan Current Page"
4. 观察扫描过程 → 记录控制台状态
5. 验证结果完整性 → 更新测试矩阵
```

## 🎓 测试维度说明

每个网站需要评估 6 个维度：

| 维度 | 说明 | 判定标准 |
|------|------|----------|
| **扫描** | 扫描是否完成 | ✅成功 / ❌失败 |
| **控制台** | Console 错误状态 | ✅无错误 / ⚠️警告 / ❌错误 |
| **评分** | 6 类别评分生成 | ✅完整 / ⚠️部分 / ❌缺失 |
| **Schema** | 结构化数据解析 | ✅成功 / ➖无Schema / ❌失败 |
| **性能** | 扫描耗时 | ✅<2s / ⚠️2-5s / ❌>5s |
| **备注** | 特殊情况记录 | 自由文本 |

## ⚠️ 重要提示

### 测试原则
1. **不以 SEO 得分高低判定测试通过/失败**
   - 目标：验证扫描稳定性
   - 即使得分很低，只要扫描完成就算成功
   
2. **失败不阻塞后续测试**
   - 记录失败原因后继续测试其他网站
   - 完成全部 20 个网站后再统计

3. **关注扩展错误，忽略页面错误**
   - 页面自身的 Console 错误不计入
   - 只记录扩展引起的错误

### 可忽略的错误
- ✅ CSP 警告（常见于新闻站点）
- ✅ 第三方脚本错误
- ✅ 广告拦截器警告
- ✅ 页面自身的业务错误

### 需关注的错误
- ❌ 扩展注入脚本失败
- ❌ 扫描过程崩溃
- ❌ 权限被拒绝
- ❌ 计算错误（NaN、除零）

### 上架决策标准

**✅ 通过 - 建议上架**
- 成功率 ≥ 90% (18/20)
- 无 P0 阻塞问题
- 静态站点 100% 成功

**⚠️ 条件通过 - 修复后上架**
- 成功率 80-89%
- P0 问题已修复
- 主流平台 ≥ 80% 成功

**❌ 不通过 - 需重大修复**
- 成功率 < 80%
- 存在未修复的 P0 问题
- 静态站点失败率 > 0

## 🐛 问题分级标准

### P0 - 阻塞级（必须修复才能上架）
- 导致扩展崩溃
- 导致浏览器标签页卡死
- 核心扫描功能完全失效
- 数据计算严重错误（NaN、Infinity）

### P1 - 严重（影响主流平台）
- 主流网站扫描失败
- 明显的功能缺陷
- 性能问题导致超时
- Schema 解析完全失效

### P2 - 一般（不影响上架）
- 边缘场景失败
- 非核心功能问题
- 轻微的 UI 显示问题
- 性能可优化但不阻塞
